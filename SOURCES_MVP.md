## Комментарии по RSS vs HTML

- **RSS предпочтительнее**, когда:
  - источник популярный и стабильный;
  - есть чёткая структура ленты.
- **HTML допустим**, когда:
  - источник очень важный (официальный сайт патриархии, епархии), но RSS нет;
  - сайт относительно простой и стабильный.

Для MVP можно:

- начать с ~25–30 источников (в основном HTML, несколько RSS);
- потом постепенно добавлять ещё, особенно те, где есть RSS.

## Примечания

- **Тип**: RSS — есть RSS-лента, HTML — только сайт с новостями.
- **Приоритет**: high — города-миллионники, medium — области и пригороды.
- **Статус**: not verified — ссылка проверена, needs_check — нужно уточнить RSS/актуальность.
- **RSS**: знак `нет` означает, что RSS не найден, `?` — нужно уточнить.
- **Подтверждённые RSS:**

- **Митрополии**: не добавляются как отдельные источники, за исключением случаев, когда у митрополии есть собственный новостной сайт (например, Санкт-Петербургская митрополия).
